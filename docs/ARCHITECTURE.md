# 架构规划

## 核心目标

生成名字时同时满足：
1. 有明确的古诗文出处（诗句 + 作者 + 典籍）
2. 符合出生八字的五行喜用神
3. 三才五格数理较优
4. 音韵、字义、文化印象综合评分

## 推荐技术路线（方案 A）

以 **babyname/fate** 为底座：

- **后端**：继续使用 Go + SQLite / Ent
- **八字引擎**：保留 chronos / yi 相关逻辑
- **诗词部分**：
  - 引入或清洗 gushi_namer 使用的精选诗库
  - 在生成结果中强制附带「出处」字段（原句、作者、书名）
- **前端**：React，参考 gushi_namer 的卡片式出处展示

## 数据流示意

1. 用户输入：姓氏 + 出生时间 + 性别 + 可选典籍偏好
2. 后端计算八字 → 得出喜用神、忌神
3. 从诗词库中筛选符合五行 + 笔画要求的候选字/词
4. 组合名字并计算五格、音韵、文化分
5. 返回带完整出处和评分的名字列表
